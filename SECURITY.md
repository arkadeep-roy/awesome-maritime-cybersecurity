# Security Policy

This is a public research and education resource, not a disclosure inbox for vulnerabilities affecting third-party maritime systems, ships, ports, satellite services, vendors, or live infrastructure.

## Repository issues

Use GitHub issues for repository maintenance only:

- Broken links
- Incorrect citations
- Outdated references
- Unsafe or poorly scoped content
- Ambiguous confidence wording
- Presentation and documentation issues

## Third-party vulnerabilities

Report third-party vulnerabilities directly to the affected organization or through an official vulnerability disclosure program. If no program exists, use a national CERT/CSIRT, sectoral ISAC, or recognized vulnerability coordination body.

Do not publish working exploit details for live maritime infrastructure in this repository.

## Repository response

Project reviewers may remove or rewrite content that enables disruption of live maritime systems or presents unverified claims as confirmed facts.
