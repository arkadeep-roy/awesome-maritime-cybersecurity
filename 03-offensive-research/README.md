# Offensive Research

This section covers maritime-specific offensive research. The focus is understanding how maritime systems fail, how exposure becomes operational risk, and how to reproduce findings in authorized environments without interfering with live safety systems.

| File | Focus |
| --- | --- |
| [Maritime offensive research map](maritime-offensive-research-map.md) | System-specific research areas for AIS, GNSS, ECDIS/S-100, NMEA, VSAT, OT, GMDSS, and port systems |
| [Maritime attack surface](maritime-attack-surface.md) | Asset classes, trust boundaries, and vulnerability classes that shape maritime exposure |
| [CISA and USCG cyber hygiene findings](cisa-uscg-cyber-hygiene-findings.md) | Official advisory findings translated into maritime offensive research questions |
| [Authorized testing methodology](authorized-testing-methodology.md) | How to scope testing, collect evidence, and write impact without touching live safety systems |

This section is not a generic web-application checklist. Web, cloud, identity, and API issues are included only when they connect to maritime functions such as vessel operations, port logistics, fleet management, chart/update distribution, satellite communications, or shipboard OT.
