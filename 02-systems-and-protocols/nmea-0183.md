# NMEA 0183

NMEA 0183 is an ASCII-based navigation data format commonly seen in maritime electronics. It can appear over serial links and over IP networks.

## Port reference

IANA lists `nmea-0183` on TCP and UDP port 10110 for navigational data. Source: [IANA service-name registry](https://www.iana.org/assignments/service-names-port-numbers/service-names-port-numbers.xhtml?search=nmea).

## Security relevance

NMEA 0183 was designed for trusted environments, not adversarial networks. Security work should focus on parsing robustness, validation, segmentation, and monitoring.

## Safe lab ideas

- Write a local parser for valid sentences.
- Validate checksums.
- Reject malformed fields.
- Log impossible jumps or malformed timestamps.
- Replay sample files into a local mock service, not real bridge equipment.

## Boundary

Operational navigation-data injection guidance is out of scope.
