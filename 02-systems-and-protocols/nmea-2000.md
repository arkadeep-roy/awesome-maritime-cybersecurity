# NMEA 2000

NMEA 2000 is based on CAN bus concepts and is used for vessel sensor and control data. It is relevant to both defensive monitoring and lab-based protocol research.

## Security relevance

As with other CAN-style environments, trust assumptions, device identity, segmentation, and gateway exposure are important security concerns.

## Safe research paths

- Study CAN security concepts in local labs.
- Use simulated frames and mock gateways.
- Build detection rules for unexpected device identity, rate anomalies, and invalid values.
- Avoid operational vessel networks.
