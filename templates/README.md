# Templates

Use these templates when adding new entries. They keep source quality, confidence labels, and testing boundaries consistent across the repository.

| Template | Use for |
| --- | --- |
| [CVE entry](cve-entry-template.md) | CVEs and vulnerability-analysis files |
| [Incident entry](incident-template.md) | Real-world incident case studies |
| [Paper entry](paper-entry-template.md) | Academic papers, whitepapers, and threat-intelligence reports |
| [Tool entry](tool-entry-template.md) | Tools, datasets, simulators, and cyber ranges |

New entries should include:

- A concise summary
- A source-quality note
- A maritime relevance statement
- A testing or live-system boundary
