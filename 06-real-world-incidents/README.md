# Real-World Incidents

This section documents public maritime cyber incidents and cyber-relevant maritime case studies. Each incident should include a confidence label.

## Confidence labels

| Label | Meaning |
| --- | --- |
| confirmed | Official victim, regulator, court, or high-confidence technical confirmation exists |
| reported | Public reporting exists, but full technical confirmation is unavailable |
| suspected | Cyber cause or contribution is plausible but not confirmed |
| contested | Sources disagree or material claims are disputed |
| illustrative | Not a cyber incident, but relevant for explaining cyber-kinetic impact |

## Contribution standard

Do not turn rumors into facts. If a source says “claimed,” “suspected,” “reported,” or “alleged,” keep that language.
