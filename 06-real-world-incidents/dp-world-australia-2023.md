# DP World Australia cybersecurity incident, 2023

## Summary

DP World Australia stated that it detected unauthorized access to its Australian corporate network on 10 November 2023. The company disconnected the network from the internet to contain the incident, which impacted landside port operations.

## Lessons

- Corporate-network compromise can affect landside port operations.
- Network disconnection may be necessary containment, but has operational consequences.
- Port incident response should plan for tradeoffs between containment and continuity.
