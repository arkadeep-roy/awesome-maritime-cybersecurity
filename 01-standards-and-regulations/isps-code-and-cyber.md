# ISPS Code and Cybersecurity

The International Ship and Port Facility Security Code is not a cybersecurity standard, but it is important context for maritime cyber because modern ship and port security increasingly depends on digital systems.

## What the ISPS Code is

IMO states that the ISPS Code entered into force under SOLAS Chapter XI-2 on 1 July 2004 and forms a mandatory security regime for international shipping.

Sources:

- [imo.org](https://www.imo.org/en/ourwork/security/pages/solas-xi-2%20isps%20code.aspx)
- [dgma.gov.in](https://dgma.gov.in/nautical-wing/nw-port-security-isps-code)

## Why cyber researchers should care

Ship and port-facility security now intersects with:

- access-control systems
- CCTV and surveillance
- port-gate systems
- communications
- identity and visitor systems
- ship security alert systems
- incident reporting
- security plans
- port-facility networks

A cyber issue can affect physical-security outcomes even when the original standard was written for broader maritime security.

## Framing

Use ISPS as operational context, not as a direct cyber compliance claim.

Preferred wording:

```text
This finding could affect systems that support ship or port-facility security functions.
```

Avoid:

```text
This is an ISPS violation.
```

unless a qualified maritime-security assessor has verified the specific requirement and context.
