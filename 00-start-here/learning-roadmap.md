# Learning Roadmap

## Phase 1: Domain foundations

- Maritime roles: ship owner, operator, manager, class society, flag state, port authority, terminal operator, vendor
- Vessel systems: navigation, communications, machinery, cargo, safety
- Ship-to-shore connectivity and remote support
- Port logistics and terminal operating systems

## Phase 2: Cyber foundations in maritime context

- IT/OT segmentation
- Identity and remote access
- Network zones and conduits
- Patch constraints at sea
- Low-bandwidth monitoring
- Incident response on vessels

## Phase 3: Systems and protocols

- AIS: vessel broadcasts and tracking data
- GNSS: positioning, spoofing, jamming, and detection
- ECDIS: chart display, update supply chain, operating-system risk
- NMEA 0183 and NMEA 2000: navigation data exchange
- VSAT/SATCOM: ship internet and remote administration
- GMDSS: distress and safety communications

## Phase 4: Offensive research

- Maritime SaaS and API testing
- Authorized recon for scoped programs
- CVE analysis
- Lab-only protocol testing
- Report writing with operational impact

## Phase 5: Defensive engineering

- Detection use cases
- AIS/GNSS anomaly monitoring
- OT segmentation
- Secure remote access
- ECDIS update hygiene
- Incident response playbooks

## Phase 6: Research contribution

- Summarize papers
- Reproduce safe lab results
- Build mock vulnerable maritime apps
- Improve source-backed case studies
- Translate useful material across languages
